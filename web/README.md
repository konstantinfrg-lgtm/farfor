# Веб-приложение для коллекционеров фарфоровых молочников

## Технологии

- **React 18** с TypeScript
- **Vite** - сборщик
- **React Router** - навигация
- **Axios** - HTTP клиент

## Установка

```bash
cd /workspace/web
npm install
```

## Запуск

```bash
npm run dev
```

Приложение будет доступно по адресу: http://localhost:3000

## Структура проекта

```
web/
├── src/

│   │   ├── Header.tsx    # Шапка сайта
```

## Функционал

### Аутентификация
- Регистрация нового пользователя
- Вход в систему
- JWT токены (хранятся в localStorage)
- Защита приватных маршрутов

### Управление коллекцией
- Просмотр всех предметов пользователя
- Добавление нового предмета со всеми атрибутами:
  - Производитель, автор формы, автор росписи
  - Название формы, название росписи
  - Год выпуска, период
  - Материал, состояние, размер
  - Место нахождения, комментарий
- Загрузка нескольких фотографий
- Редактирование существующих предметов
- Удаление предметов
- Переключение видимости (публичный/приватный)

### Поиск и фильтрация
- Поиск по названию, производителю, авторам
- Фильтрация в реальном времени

### Публичный доступ
- Просмотр публичных коллекций без регистрации
- Детальная информация о каждом предмете
- Имя коллекционера для публичных предметов

## Дизайн

- Спокойный музейный стиль
- Теплая коричневая цветовая гамма (#8D6E63, #6D4C41)
- Шрифты: Playfair Display (заголовки), Roboto (текст)
- Акцент на фотографиях предметов
- Адаптивный дизайн для мобильных устройств

## API

Приложение работает с backend на FastAPI (порт 8000).
Прокси настроен в vite.config.ts.

## Сборка для продакшена

```bash
npm run build
```

Файлы будут в папке `dist/`.
